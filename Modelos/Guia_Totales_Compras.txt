 GUÍA DE REFERENCIA: TOTALES Y RESUMEN EN CARGA DE COMPRAS
==========================================================

Este documento detalla dónde se encuentra la lógica de los campos (Neto, IVA, Percepciones, etc.) 
en la pantalla de Carga de Compras.

1. VISTA Y DISEÑO (HTML / ETIQUETAS)
------------------------------------
Archivo: templates\facturacion\compras_carga.html
Líneas: 221 a 284
Descripción: Aquí están los labels (<label>) y los inputs (<input>) de:
- Neto Gravado
- IVA Facturado
- Perc. IIBB
- Perc. IVA
- Otros Imp.
- Liquidación (Display azul)
- Total Comprobante (Bloque negro)

2. LÓGICA DE CÁLCULO EN TIEMPO REAL (JAVASCRIPT)
------------------------------------------------
Archivo: templates\facturacion\compras_carga.html
Función: recalculateFinal()
Línea: 373
Descripción: Suma todos los inputs de impuestos y actualiza el "Total Comprobante".

Archivo: templates\facturacion\partials\compra_items_tabla.html
Script al final: Línea 68
Descripción: Suma el total de la grilla de productos y actualiza automáticamente 
el campo "Neto Gravado" del formulario principal.

3. PROCESAMIENTO Y GUARDADO (DJANGO / PYTHON)
---------------------------------------------
Archivo: facturacion\views.py
Clase: ComprasCargaView -> método post()
Línea: 160
Descripción: Recibe los datos, los limpia de formato (quita puntos de miles) y los guarda.
Importante: La lista 'campos_monetarios' en la línea 164 define qué campos se limpian.

4. BASE DE DATOS (MODELOS)
--------------------------
Archivo: facturacion\models.py
Clase: Compra(models.Model)
Línea: 92
Descripción: Define la estructura en la DB. Los campos clave son:
- neto, iva, p_iibb, p_iva, otros, total.

---
INSTRUCCIONES RÁPIDAS PARA MODIFICAR:
1. Para cambiar un nombre: Editar el <label> en 'compras_carga.html'.
2. Para añadir un impuesto:
   a. Añadir al modelo en 'models.py'.
   b. Añadir el input en 'compras_carga.html'.
   c. Añadir el ID al array 'c' en la función 'recalculateFinal()' de 'compras_carga.html'.
   d. Añadir el nombre al array 'campos_monetarios' en 'views.py'.
3. Para cálculos porcentuales: Modificar la función 'recalculateFinal()' en 'compras_carga.html'
   añadiendo la fórmula matemática (ej: netoVal * 0.03).
   Hacer cálculos automáticos (Porcentuales)
   Si quieres que, por ejemplo, la Perc. IIBB se calcule sola como el 3% del Neto, debes tocar la función recalculateFinal en el JS de compras_carga.html:

javascript
   // Ejemplo de lógica para cálculo automático
   function recalculateFinal() {
   const netoStr = document.getElementById('id_neto').value;
   const netoVal = parseAR(netoStr);
    
   // Si quisieras que IIBB sea el 3.5% automático:
   const iibbAuto = netoVal * 0.035;
   document.getElementById('id_p_iibb').value = fMiles(iibbAuto); // Lo muestra en el input
    
   // ... resto de la lógica de suma ...
}

En el archivo 'compras_carga.html'. Líneas 220. Verás los bloques de cada input.
