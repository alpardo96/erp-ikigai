Capturar / Importar Productos en Excel

Actualización masiva de precios, costos y alta automática de nuevos artículos

Instrucciones importantes para la captura:

  • Para corregir/actualizar productos existentes: Mantenga intacta la columna ID del producto.
  • Para productos nuevos: No le ponga el ID (deje la celda vacía). El sistema lo agregará automáticamente y le asignará el ID correspondiente.
  • Marcas, Rubros y Familias: Si escribe nombres de Marcas, Rubros o Familias no registrados previamente, el sistema los creará automáticamente en MAYÚSCULAS y los vinculará al producto.
  • Todos los textos ingresados se unificarán automáticamente en MAYÚSCULAS.
